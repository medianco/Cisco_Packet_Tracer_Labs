# Cisco Enterprise Branch Network Lab

## 📖 Overview

This project is a comprehensive **Cisco Enterprise Branch Network Lab** that simulates a real-world enterprise branch infrastructure using Cisco networking technologies.

The topology demonstrates a secure, redundant, and highly available enterprise network that integrates Internet connectivity, dual ISPs, perimeter firewalls, a collapsed core architecture, wireless infrastructure, IP telephony, DMZ services, and enterprise server resources.

The lab is designed to provide hands-on experience with enterprise networking concepts commonly deployed in medium to large organizations.

---

# 🏗️ Network Architecture

The topology is organized into the following components:

- Internet Cloud
- Dual Internet Service Providers (ISP)
- Dual Perimeter Firewalls
- Collapsed Core Layer
- Access Layer
- Wireless Infrastructure
- Voice Network
- Enterprise Server Farm
- DMZ Network
- End Users

The design emphasizes redundancy, security, scalability, and high availability.

# 🏢 DMZ Services

The DMZ hosts public-facing services including:

- Web Server
- FTP Server
- Email Server
- Application Server
- NAS Storage Server

The DMZ is isolated from the internal network to improve security while allowing controlled public access.

- DHCP Server
- DNS Server

- Wireless LAN Controller (WLC)

These services support authentication, IP address management, wireless connectivity, and IP telephony.
